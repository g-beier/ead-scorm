# Princípios gerais dos pacotes SCORM do curso

Valem para todos os pacotes, não só para um estudo de caso.

- **Acessível**: texto legível e com contraste suficiente; botões e links com rótulo claro para leitor de tela; navegação possível pelo teclado; alternativas textuais para qualquer elemento visual.
- **Responsivo e com tamanho adequado**: a tela deve caber na altura do quadro incorporado do Moodle (fixa, não configurável pelo professor; medida em 666,5px). Deve funcionar em celular, sem rolagem horizontal e com alvos de toque de pelo menos 44px.
- **Sem conteúdo escondido**: nada obrigatório pode depender de descobrir um botão, aba ou modal. Quando não cabe, dividir em mais telas.
- **Evitar modal em telas pequenas**: usar cartão (expansível quando for o caso) ou tela própria.
- **Interação durante a leitura**: intercalar quiz, arrastar e ordenar, em vez de blocos só de texto.
- **Conclusão depende da leitura completa**: a conclusão só acontece depois de visitar todas as telas exigidas. Tarefas, textos adicionais, sugestões, modais e perguntas entram na contagem. O progresso é gravado para retomada.
- **Uma única barra de rolagem**: o conteúdo rola dentro de uma área só.
- **Referências ao longo do material**: citar fontes no ponto em que o conteúdo as usa, com link quando houver URL.
